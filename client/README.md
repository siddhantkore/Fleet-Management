# Client - Fleet Management System Frontend

This directory contains the React frontend for the Fleet Management System. It provides a comprehensive SPA for visualizing routing, tracking vehicles, and managing resources.

## Architecture Highlights
- **React 19 & Vite**: Fast development and optimized production builds.
- **React Router v6**: Client-side routing with nested layouts.
- **React-Leaflet**: Interactive map rendering for routes, live tracking, and plant locations.
- **Axios**: Centralized API requests via `src/services/api.js` instance.

## Application Structure

The application is composed of several distinct modules/pages located in `src/pages/`:

- **Dashboard.jsx**: The main administrative shell containing the navigation sidebar and layout container.
- **TripManagement.jsx**: Interface for scheduling new trips, assigning drivers and vehicles, preventing overlaps, and displaying the planned path on a map.
- **RouteAnalysis.jsx**: Compares multiple routes generated by OpenRouteService (fastest, shortest, eco) and presents AI-generated narrative insights.
- **LiveTrackingPage.jsx**: Connects via WebSockets to display real-time vehicle movements on the map.
- **FleetIntelligence.jsx**: Dashboard for viewing and acting on vehicle repositioning recommendations (Return to Base vs. Reposition).
- **Reports.jsx**: Data grids and filtering for trips, vehicles, drivers, and plants, with one-click CSV export functionality.
- **ResourceAnalysis.jsx**: High-level view of where drivers and vehicles are currently located across various plants.

## Running Locally

1. Ensure Node.js (v18+) is installed.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the Vite development server:
   ```bash
   npm run dev
   ```

## Environment Variables
Create a `.env` file in the `client/` directory with the following variables:
- `VITE_API_URL=http://localhost:8000/api/v1` (or your backend URL)
- `VITE_WS_URL=ws://localhost:8000/api/v1` (or your backend WS URL)

## Build for Production

To generate a static build suitable for Nginx or other web servers:
```bash
npm run build
```
Output will be generated in the `dist/` directory.
